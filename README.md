# Baad Data Analytics

A bilingual portfolio website for a fictional Saudi data analytics and financial reporting consultancy. English is the default language, with a complete Arabic RTL experience.

## Highlights

- Interactive executive dashboard with responsive financial charts
- Reporting-period filters and downloadable sample CSV report
- English/Arabic language switch with full RTL support
- Service positioning, fictional case studies, and a five-step delivery process
- Qualified project inquiry flow with validation and success state
- Responsive navigation and layouts for desktop, tablet, and mobile
- Clear demo-data labelling throughout
- Production health endpoint and Railway deployment configuration

## Local development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

Health check: `/health`

## Important

This is a fictional portfolio project. All company information, metrics, case studies, contact details, and financial data are demonstrative only.
